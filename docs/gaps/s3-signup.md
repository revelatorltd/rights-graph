## Decided here rather than asked

- **The contact is proved before the ArtistID exists.** The account is created when the code checks, at Basic, and from then on the wizard can't go back past it (the map won't return to You or Sign-in code).
- **An ID check never blocks claiming.** Failed or left for later, the person still claims; a label can vouch for someone whose document failed. They just can't reach Verified + ID.
- **"Needs another photo" is not a result.** Nothing is recorded; only Passed and Failed are written to the ArtistID.
- **One confirmer per sign-up**: the label (in Pro) or Sureel, with an optional evidence file for Sureel. Further claims from Profile › Claimed profiles choose again.
- **Confirming lifts the level at once.** Verified, or Verified + ID if a check has passed. The level is written onto the ArtistID's party and every confirmed entry, so the rest of the app reads it as `party.assurance`.
- **Writer mode follows the role**: Writer or Both opens the app in writer mode (Works, Societies).
